## v0.7.1

- **Fixed: the "Version 0.7.0 is ready to install" message kept coming back on Macs.** On Macs where Nowtify was installed by IT, clicking **Restart now** couldn't replace the app, so it reopened on the old version and asked again. Nowtify now recognizes these Macs and leaves updates to IT, showing the new version grayed out with "Kept up to date by your IT administrator" instead of the install message. On Macs where you installed Nowtify yourself, updates now install more safely: if anything goes wrong, your current version stays in place and you won't be asked again for that version.
